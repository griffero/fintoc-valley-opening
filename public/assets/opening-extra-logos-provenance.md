# Historical opening logo assets

Downloaded 2026-09-07 from Wikimedia Commons; original download bytes preserved. All have real SVG paths, no bitmap embeds and no font dependency.

## eBay

`ebay-1999-2012.svg`: pre-2012 overlapping multi-color eBay wordmark. 1542.977 × 642.07. Commons identifies it as the 1999–2012 mark. Upload history traces the original vector extraction to eBay's official 2001 annual report PDF, with 2008 fixes to overlapping shapes/colors. Current file contains that geometry with metadata removed in 2019.

- Description: https://commons.wikimedia.org/wiki/File:EBay_former_logo.svg
- Original SVG: https://upload.wikimedia.org/wikipedia/commons/1/11/EBay_former_logo.svg
- Historical original PDF cited by Commons: http://investor.ebay.com/downloads/2001_annual_10K.pdf

## Intel

`intel-2006-2020.svg`: blue Intel wordmark surrounded by the oval/swirl. 1004.988 × 662.729. 2 compound paths within a transformed group. The large path contains most logo pieces; preserve subpaths/holes when converting to Three.js shapes.

- Description: https://commons.wikimedia.org/wiki/File:Intel_logo_(2006-2020).svg
- Original SVG: https://upload.wikimedia.org/wikipedia/commons/7/7d/Intel_logo_%282006-2020%29.svg
- Official date verification: https://www.intel.com/pressroom/archive/releases/2006/20060103corp.htm

The request called it the “2005 Intel oval”; the recognizable oval corporate logo was formally launched on January 3, 2006. This is that mark, not the older dropped-e mark.

## Myspace

`myspace-2008.svg`: historical three connected people silhouettes + rounded lowercase `myspace.com` + `a place for friends` tagline. 295.214 × 51.633. Commons upload dates from May 20, 2008 and states it was extracted from the official Myspace PDF below. Includes an unused large Adobe Illustrator pattern definition; visible art is all real vector geometry.

`myspace-2008-clean.svg`: convenience derivative, same visible vector paths, with ONLY the unused `Polka_Dot_Pattern` definition removed. No geometry redrawn or changed. Prefer this file for SVGLoader if using the earlier brand.

- Description: https://commons.wikimedia.org/wiki/File:MySpace_logo.svg
- Original SVG: https://upload.wikimedia.org/wikipedia/commons/2/20/MySpace_logo.svg
- Official PDF cited by Commons: http://creative.myspace.com/dk/dma/downloads/DMA08_Program.pdf

`myspace-2013.svg`: alternative later people + heavy lowercase `myspace` wordmark. 829.95 × 124.84. Three separated people, unlike the overlapping/connected 2008 silhouettes. Wikimedia says the mark was launched in 2012 for the 2013 interface and references the official pressroom assets. Included so the parent can match the specific opening reference.

- Description: https://commons.wikimedia.org/wiki/File:Myspacelogo2013.svg
- Original SVG: https://upload.wikimedia.org/wikipedia/commons/4/48/Myspacelogo2013.svg
- Official pressroom asset page cited by Commons: https://new.myspace.com/pressroom/assetslogos

Confidence high for brand identities and eras. Exact Myspace version used in the user's specific opening reference requires matching that reference; both authentic options are supplied.

All four original description pages label the art PD-textlogo with trademark notices. Full description page HTML snapshots and JSON hashes/source URLs are saved alongside the assets. Quick Look PNGs are inspection thumbnails only; their square thumbnail canvas may crop larger SVGs, so use original SVG for production.
